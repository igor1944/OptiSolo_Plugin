# OptiSolo — персональные миры 10k × 10k

Плагин для **Paper 1.18.2 (Java 17)**. Каждый игрок создаёт себе личный мир **10000 × 10000 блоков**,
приглашает друзей, выдаёт доверенный доступ, управляет всё через удобное **GUI-меню**.

Внутри: **система телепортов-точек**, **отдельная система жалоб (репортов)**,
**стартовый набор инструментов** и **раздельные инвентари** — соло-миры никак не влияют на обычную игру.

## Возможности

- **Личный мир для каждого игрока** — 10000 × 10000 (граница мира, центр 0,0).
- **3 типа мира**: `NORMAL` (обычный), `FLAT` (плоский), `VOID` (пустота с платформой).
- **Друзья**: приглашения по времени (`/solo invite`), принятие (`/solo accept`), открытые/закрытые миры.
- **Доверенные**: только владелец и доверенные могут строить; гости могут только смотреть.
- **GUI-меню** (`/solo`): создание, телепорты, доступы, точки, настройки, кит, жалобы, удаление.
- **Телепорты**: личные точки внутри мира (`/solo sethome`, `/solo home <название>`).
- **Репорты**: `/solo report <ник> <причина>`, у админов — GUI жалоб с закрытием/удалением.
- **Стартовый кит**: меч, кирка, топор, лопата, хлеб, факелы, доски — настраивается в `config.yml`.
- **Раздельные инвентари**: вещи из выживания не уходят в соло-мир и наоборот (инвентарь, броня, эндер-сундук, опыт, здоровье, режим игры).

## Оптимизация (не грузит сервер)

- Миры **загружаются только когда в них заходят** и **выгружаются**, когда пустые (по умолчанию через 5 минут).
- `keep-spawn-in-memory: false` — спавн пустых миров не висит в памяти.
- Свои `view-distance` / `simulation-distance` для соло-миров (по умолчанию 6/5).
- Лимит одновременно загруженных миров (`max-loaded-worlds`, по умолчанию 20).
- Порталы в ад/энд **отключены** (иначе это +2 мира на каждого игрока).
- Плагин трогает **только свои миры** — обычная игра не затрагивается вообще.

## Установка

1. Соберите jar (см. ниже) или возьмите готовый `OptiSolo-1.0.0.jar`.
2. Положите в `plugins/` сервера **Paper 1.18.2** (Java 17).
3. Перезапустите сервер, настройте `plugins/OptiSolo/config.yml` под себя.
4. Готово: игроки пишут `/solo`.

## Сборка

```bash
mvn clean package
# jar появится в target/OptiSolo-1.0.0.jar
```

Требуется JDK 17 + Maven.

## Команды

| Команда | Описание |
|---|---|
| `/solo` | Открыть меню |
| `/solo create [normal\|flat\|void]` | Создать свой мир |
| `/solo go` | Телепорт в свой мир |
| `/solo leave` | Вернуться в обычный мир |
| `/solo invite <ник>` | Пригласить друга (10 минут) |
| `/solo accept <ник>` | Принять приглашение |
| `/solo visit <ник>` | Зайти в мир друга |
| `/solo trust <ник>` | Добавить в доверенные (может строить) |
| `/solo untrust <ник>` | Убрать из доверенных |
| `/solo members` | Меню доступов |
| `/solo sethome <название>` | Сохранить точку телепорта |
| `/solo home [название]` | Телепорт на точку (без названия — домой) |
| `/solo delhome <название>` | Удалить точку |
| `/solo kit` | Стартовый набор (кулдаун 24ч) |
| `/solo time <day\|night>` | Время в своём мире |
| `/solo weather <clear\|rain>` | Погода в своём мире |
| `/solo difficulty <...>` | Сложность мира |
| `/solo public` / `/solo private` | Открыть/закрыть мир для всех |
| `/solo report <ник> <причина>` | Пожаловаться |
| `/solo reports` | Мои жалобы (админам — все) |
| `/solo delete` | Удалить свой мир (с подтверждением) |

Алиасы: `/isolo`, `/mysolo`, `/sw`.

## Права

- `optisolo.use` (по умолчанию: всем) — пользоваться мирами.
- `optisolo.admin` (по умолчанию: OP) — админка, bypass защиты в чужих мирах, жалобы.

## Роли в мире

- **Владелец** — полный доступ, настройки, точки, удаление.
- **Доверенный** — может строить, ломать, пользоваться точками.
- **Гость** (по приглашению / в открытом мире) — только смотреть и ходить. Может открывать двери/кнопки (настраивается), бить мобов — по настройке.

## Файлы данных

- `plugins/OptiSolo/worlds/<uuid>.yml` — владелец, доверенные, приглашения, точки.
- `plugins/OptiSolo/players/<uuid>.yml` — инвентари main/solo, последняя позиция, кулдаун кита.
- `plugins/OptiSolo/reports.yml` — жалобы.
- Папки миров: `solo_<uuid>` в корне сервера.

## FAQ

**Это не лагает?**
Нет, если игроков не сотни одновременно в своих мирах. Пустые миры выгружаются и не занимают RAM/CPU.
Уменьшите `view-distance` и `unload-after-minutes-empty`, если сервер слабый.

**Вещи из выживания пропадут?**
Нет. При входе в соло-мир инвентарь выживания сохраняется, выдаётся отдельный. При выходе — возвращается.
Даже при крахе сервера данные восстанавливаются из файлов.

**Мир друга грузится, когда его нет онлайн?**
Да, по требованию (загрузился → зашли → вышли → через N минут выгрузился). Можно запретить визиты без владельца:
`invites.allow-offline-owner-visit: false`.

**Как изменить стартовый набор?**
Секция `starter-kit` в `config.yml`, формат `МАТЕРИАЛ:КОЛИЧЕСТВО`, затем `/solo reload`.
